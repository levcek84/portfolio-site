# Renato Koštomaj — portfolio

Dvojezična osebna predstavitvena stran, izdelana z Reactom in Vite. Vključuje odzivno postavitev, interaktivne kartice, animacije z upoštevanjem nastavitev za zmanjšano gibanje ter slovenski in angleški CV za prenos.

## Lokalni zagon

```bash
npm install
npm run dev
```

Preverjanje pred objavo:

```bash
npm run lint
npm run build
npm run preview
```

## Objavljanje

Potisk na vejo `main` sproži GitHub Actions in objavi vsebino mape `dist` na GitHub Pages. V nastavitvah repozitorija mora biti pod **Settings → Pages → Source** izbrano **GitHub Actions**.

## Zasebni dokumenti

Izvirna potrdila in priporočila so shranjena le lokalno v `deliverables/private-originals/`. Mapa je izključena iz Gita; na spletni strani so objavljeni samo varni povzetki brez osebnih identifikacijskih podatkov.
